About the workshops

Learn by building

Plenty of students are curious about AI, but the field can be hard to approach. It’s technical and it moves fast. Our Machine Learning Workshop Series combines short theory with practical examples and coding exercises, so you leave with something that works.

Sessions range from data exploration, classification, regression and clustering to deep learning, Transformers and Large Language Models. Basic Python is all you need to get started.
